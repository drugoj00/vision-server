# Vision Server

**RU.** Дополнение для [Vision для Windows](https://github.com/drugoj00/vision-for-windows), работает в фоне. Компьютер раздаёт торренты по сети, Vision для Android подключается к нему в **Настройки > Движок > Внешний сервер**.

- Адрес, ключ доступа и QR-код на странице **Сервер** в Vision для Windows
- Запуск и остановка, порт, доступ из сети, запуск вместе с Windows
- Клиенты и журнал запросов
- Работает в фоне без окна, протокол тот же, что ждёт клиент для Android
- Русский, украинский, английский

**Установка:** в Vision для Windows откройте **Сервер** и нажмите **Установить**. Программа сама выберет файл для вашей Windows и проверит SHA-256. Без интернета: **Установить из файла** и zip со страницы [Releases](https://github.com/drugoj00/vision-server/releases/latest).

| Файл | Windows | Движок |
|---|---|---|
| `Vision-Server-1.0-win-x64.zip` | 64-разрядная | классический и быстрый |
| `Vision-Server-1.0-win-x86.zip` | 32-разрядная | классический и быстрый |
| `Vision-Server-1.0-win-arm64.zip` | ARM64 | только быстрый (Go) |

В сборке для ARM64 нет классического движка (libtorrent): под Windows ARM64 его не существует. Торренты играет быстрый движок Go, полной загрузки на диск нет.

Контрольные суммы: `SHA256.txt` в каждом выпуске.

Vision Server скачивается отдельно. Для просмотра и загрузок Vision для Windows он не нужен.

**Требования:** Windows 10 и новее, Vision для Windows. Один раз разрешите программу в брандмауэре (кнопка на странице Сервер).

**Новости и помощь:** [Telegram-канал](https://t.me/PhoneInWindowSound), [все наши программы](https://drugoj00.github.io/).
