# Vision Server

**UK.** Додаток для [Vision для Windows](https://github.com/drugoj00/vision-for-windows), працює у фоні. Комп'ютер роздає торенти мережею, Vision для Android підключається до нього в **Налаштування > Рушій > Зовнішній сервер**.

- Адреса, ключ доступу та QR-код на сторінці **Сервер** у Vision для Windows
- Запуск і зупинка, порт, доступ із мережі, запуск разом із Windows
- Клієнти й журнал запитів
- Працює у фоні без вікна, протокол той самий, що очікує клієнт для Android
- Українська, російська, англійська

**Встановлення:** у Vision для Windows відкрийте **Сервер** і натисніть **Встановити**. Програма сама вибере файл для вашої Windows і перевірить SHA-256. Без інтернету: **Встановити з файлу** та zip зі сторінки [Releases](https://github.com/drugoj00/vision-server/releases/latest).

| Файл | Windows | Рушій |
|---|---|---|
| `Vision-Server-1.0-win-x64.zip` | 64-розрядна | класичний і швидкий |
| `Vision-Server-1.0-win-x86.zip` | 32-розрядна | класичний і швидкий |
| `Vision-Server-1.0-win-arm64.zip` | ARM64 | лише швидкий (Go) |

У збірці для ARM64 немає класичного рушія (libtorrent): під Windows ARM64 його не існує. Торенти грає швидкий рушій Go, повного завантаження на диск немає.

Контрольні суми: `SHA256.txt` у кожному випуску.

Vision Server завантажується окремо. Для перегляду й завантажень Vision для Windows він не потрібен.

**Вимоги:** Windows 10 і новіша, Vision для Windows. Один раз дозвольте програму в брандмауері (кнопка на сторінці Сервер).

**Новини та допомога:** [Telegram-канал](https://t.me/PhoneInWindowSound), [усі наші програми](https://drugoj00.github.io/).

Якщо додаток корисний, поставте зірку репозиторію.
